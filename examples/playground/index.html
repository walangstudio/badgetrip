Config

How to write the config

It's JSON: quote every key, no comments, no trailing commas, no imports or functions. Apply checks all of it and lists every mistake.

celebrations
What createCelebrationResolver takes: layouts, positions, sounds, confetti and animation.
theme
What defineTheme takes, without name. It's layered on the Theme picker: style colors and gradients, icons, and its own celebrations.

Images are URLs. Files in the playground's samples/ folder work as "samples/star.gif". Sounds are a built-in name (chime, fanfare, sparkle, pop), a URL, or notes: {"tones": [{"freq": 880, "at": 0, "dur": 0.3}]}. Each sample in Start from shows one topic. The guides cover every option.
